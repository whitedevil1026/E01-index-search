# E01 Index & Search — dependencies
#
# PYTHON VERSION
# --------------
# Targets Python 3.12. The project was originally pinned to 3.10, which
# reaches end of life on 31 October 2026; every version below was
# verified to install from a cp312 binary wheel on Windows x64 on
# 2026-10-18, so no Microsoft C++ Build Tools are needed.
#
#     py -3.12 -m venv .venv312
#     .venv312\Scripts\python -m pip install -r requirements.txt
#
# Install one group at a time if pip reports "resolution-too-deep" —
# the libyal family plus PySide6 can exceed pip's resolver depth when
# every package is passed in a single command.
#
# OFFLINE INSTALL
# ---------------
# Bundles live one per interpreter under wheels/: wheels/py312 is the
# current Python 3.12 bundle and wheels/py310 is the legacy Python 3.10
# one (a wheel is tagged for one CPython minor version, so each bundle
# only works on its own interpreter). Install from the 3.12 bundle with
# no network at all:
#
#     .venv312\Scripts\python -m pip install --no-index --find-links wheels/py312 -r requirements.txt
#
# To rebuild the 3.12 bundle (needs network once):
#
#     py -3.12 -m pip download -r requirements.txt -d wheels/py312 --prefer-binary
#     py -3.12 -m pip download setuptools wheel -d wheels/py312 --only-binary :all:
#
# setuptools and wheel must be in the bundle: two dependencies
# (red-black-tree-mod, win_unicode_console) publish no wheel, and
# building their sdists offline needs setuptools present. Both are pure
# Python, so no C++ compiler is required — verified 2026-10-18, a fresh
# 3.12 venv installed all 19 modules from the bundle with --no-index.
